\# CRTBP Project (Earth–Moon)



Python toolkit for simulating trajectories in the Circular Restricted Three-Body Problem (CRTBP),

with event detection and Jacobi constant monitoring.



\## Features

\- CRTBP equations of motion (normalized units)

\- High-accuracy propagation

\- Event detection (e.g., y=0 crossings)

\- Jacobi constant drift diagnostics

\- Example scripts and pytest test suite
