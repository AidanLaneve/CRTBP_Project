\# CRTBP / CR3BP Orbital Modeling Tool — Roadmap (Phases 0–10)This roadmap tracks the build-out of an Earth–Moon \*\*Circular Restricted Three-Body Problem (CRTBP / CR3BP)\*\* toolkit in Python. The end goal is a user-facing tool that can compute equilibrium points, diagnose stability, visualize forbidden regions, generate periodic orbit families (Lyapunov / Halo / NRHO-like), analyze Floquet stability, and compute stable/unstable manifolds—packaged as a reproducible CLI-ready project with tests and exports.---\## Phase 0 — Spec + Architecture (Project Foundation)\*\*Objective:\*\* Establish conventions, structure, and a plan that prevents rework later.\*\*Deliverables\*\*\- Clear scope statement: Earth–Moon CRTBP as the primary system.\- Repository structure (modules for dynamics, numerics, plotting, utilities, tests).\- Coordinate/frame conventions documented:  - Rotating barycentric nondimensional frame (typical CR3BP normalization).  - Primary/secondary definitions, mass parameter `μ`, units, and sign conventions.\- Coding standards: type hints, docstrings, error handling, consistent naming.\- Minimal CI-friendly test harness skeleton (pytest setup, basic smoke tests).---\## Phase 1 — CRTBP Propagator + Events + Jacobi Drift Monitoring\*\*Objective:\*\* Build a correct, testable equations-of-motion propagator with diagnostics.\*\*Deliverables\*\*\- CRTBP equations of motion in rotating frame: `f(t, state, μ)` for integration.\- Integrator wrapper (e.g., `solve\\\\\\\_ivp`) with:  - uniform sampling outputs  - event detection hooks (plane crossings, x-axis crossings, etc.)\- \*\*Jacobi constant\*\* computation `C(state, μ)` and drift monitoring over propagation.\- Test coverage:  - propagation sanity checks  - Jacobi drift small for appropriate tolerances/step settings  - event detection returns expected crossings\- Documentation:  - README with install/run examples  - “Conventions” doc for frames, units, normalization, and sign conventions  - roadmap reference (this file)---\## Phase 2 — Lagrange Points + Linear Stability + Jacobi at Li\*\*Objective:\*\* Compute equilibrium points and characterize local linear dynamics.\*\*Deliverables\*\*\- Compute all 5 Lagrange points \*\*L1–L5\*\* for given `μ`  - robust root-finding for collinear points (L1–L3)  - analytic or direct solve for triangular points (L4–L5)\- Linearization / Jacobian of CRTBP at equilibrium points\- Eigenvalue-based stability classification (center/saddle behavior)\- Compute and report `C(Li)` (Jacobi constant at each equilibrium point)\- Plot: equilibrium locations + primaries in rotating frame---\## Phase 3 — Zero-Velocity Curves (ZVC) + Forbidden Regions + Neck Opening\*\*Objective:\*\* Visualize energetically accessible regions in the rotating frame.\*\*Deliverables\*\*\- ZVC computation on a 2D grid (planar case, typically `y–x` plane)\- Mask/plot forbidden vs allowed regions for a given Jacobi constant `C`\- Highlight “neck opening” behavior near L1/L2 as `C` changes\- Plot utilities:  - contour of `C(x,y)` or equivalent ZVC representation  - overlays: primaries and L-points---\## Phase 4 — Variational Equations + State Transition Matrix (STM) + Validation\*\*Objective:\*\* Enable sensitivity analysis and the backbone for orbit correction/stability.\*\*Deliverables\*\*\- Implement variational equations: propagate both state and STM `Φ(t)`\- Numerical stability considerations (reshape STM, tolerances, conditioning)\- Validation:  - compare STM predictions vs finite-difference perturbations  - unit tests that confirm STM accuracy within tolerance---\## Phase 5 — Planar Lyapunov Orbits via Single-Shooting Differential Correction\*\*Objective:\*\* Generate periodic planar Lyapunov orbits around L1/L2 reliably.\*\*Deliverables\*\*\- Single-shooting differential correction algorithm  - choose symmetry plane crossing condition (e.g., `y=0` crossing)  - target constraints for periodicity (typical: enforce `y=0`, `vx=0`, etc.)\- Continuation strategy for family growth (increment amplitude/energy)\- Outputs:  - initial conditions + period for converged orbits  - plots of orbits in rotating frame\- Tests:  - periodicity residual norms are small  - Jacobi constant consistency for corrected solutions---\## Phase 6 — Continuation to Orbit Families + Family Visualization\*\*Objective:\*\* Turn single solutions into organized families with robust continuation.\*\*Deliverables\*\*\- Continuation driver:  - predictor-corrector continuation (simple secant predictor acceptable)  - track family parameter (e.g., `C`, x-amplitude, or period)\- Family products:  - Lyapunov family curves  - metadata tables: (ICs, period, Jacobi, convergence metrics)\- Plot suite:  - family overlays  - parameter-vs-parameter plots (e.g., period vs C)---\## Phase 7 — 3D Halo + NRHO-like Members (Correction + Continuation)\*\*Objective:\*\* Extend to 3D periodic orbits and “NRHO-like” solutions.\*\*Deliverables\*\*\- 3D differential correction method (multi-constraint shooting)  - typical halo generation near L1/L2 from linearized seed + correction\- Continuation from small-amplitude halos to larger members\- “NRHO-like” orbit generation approach:  - continuation / targeting into high-eccentricity L2 region solutions  - clearly document that these are CRTBP analogs (“NRHO-like”) not full ephemeris NRHOs\- Visualizations:  - 3D orbit plots (x–y–z) and projections  - family overlays---\## Phase 8 — Floquet Stability Across Families (Monodromy + Multipliers)\*\*Objective:\*\* Quantify orbital stability using Floquet theory.\*\*Deliverables\*\*\- Compute monodromy matrix `M = Φ(T)` from STM at one period\- Compute Floquet multipliers (eigenvalues of `M`)\- Stability classification:  - identify stable/unstable directions (multipliers outside unit circle)  - summarize for each family member\- Plots:  - multipliers vs family parameter  - stability indices (as appropriate)---\## Phase 9 — Stable/Unstable Manifolds from Monodromy Eigenstructure\*\*Objective:\*\* Generate invariant manifolds for transfer design and dynamical insight.\*\*Deliverables\*\*\- Extract eigenvectors corresponding to stable/unstable multipliers\- Perturb periodic orbit ICs along eigenvectors to seed manifold arcs\- Propagate manifold trajectories forward/backward in time\- Visualizations:  - manifold tubes / trajectory bundles  - intersections with sections (optional but useful)---\## Phase 10 — Productize as a CLI Tool + Presets + Export + Tests + README\*\*Objective:\*\* Make the project reproducible, usable, and shareable.\*\*Deliverables\*\*\- CLI interface (e.g., `crtbp` command) with presets:  - Earth–Moon default `μ` and typical normalization details  - commands to compute: L-points, ZVC, orbit families, multipliers, manifolds\- Export formats:  - CSV/JSON for ICs and metadata  - optional trajectory dumps and plot saving\- Testing suite:  - core numerical correctness tests  - regression tests for family generation (within tolerance)---\## Notes / Scope Control\- This roadmap focuses on \*\*CRTBP\*\*. Higher-fidelity models (e.g., ER3BP, J2, bicircular) are intentionally out of scope for Phases 0–10.\- “NRHO-like” here means CRTBP analog behavior; true NRHOs are defined in ephemeris models.
